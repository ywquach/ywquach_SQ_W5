# Super Mario Bros. Themed Maze Game

## Setup and Interaction Instructions

To run the sketch locally, open `https://ywquach.github.io/ywquach_SQ_W5/` in Google Chrome using Live Server.

**Controls:** WASD to move.

Collect all 3 coins, then reach the flagpole tile (turns gold once unlocked) to clear the level.

**Opening the Chrome Console**

- **Windows:** Press `F12` or `Ctrl + Shift + J`, then click the **Console** tab
- **Mac:** Press `Cmd + Option + J`

The console will show any errors in your sketch.

## About This Version

This is a Mario-themed reskin of a shared group-project maze template. The core
game mechanics (movement, wall collision, coin collection, win condition) are
unchanged from the original template. What changed is the visual layer: a new
character sprite sheet, a new coin sprite sheet, a redesigned brick/sky tile
palette, a reworked HUD, and a new win screen.
